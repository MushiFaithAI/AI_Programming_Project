## Project Title
Customer Purchase Prediction System

## Project Description
This project demonstrates a basic machine learning system that predicts whether a customer will make a purchase based on their Age and Salary. The project uses Logistic Regression, a supervised learning algorithm, to classify customers into “Yes” (purchased) or “No” (not purchased).

## Python Libraries Used
- pandas
- scikit-learn

## How to Run the Project
1. Clone the repository:
   git clone https://github.com/FaithKemuma/AI_Programming_Project.git

2. Navigate to the project folder:
   cd AI_Programming_Project

3. Install required libraries:
   pip install -r requirements.txt

4. Run the program:
   python main.py

   ## Notes
 The dataset used in this project is small and intended only for demonstration/illustration purposes.
